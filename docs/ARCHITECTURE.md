# Architecture Overview

## System Overview
This site uses the HTML5 UP Dimension template, customized for MP Barbosa's portfolio. It is structured for easy integration with sibling projects.

## Directory Structure
- `src/` - Source code (components, pages, assets)
- `docs/` - Documentation
- `config/` - Configuration files

## Key Components
- React components for UI
- Static assets for images and styles

## Integration
Sibling projects can be linked or embedded as needed.
