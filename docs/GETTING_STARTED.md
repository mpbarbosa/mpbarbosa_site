# Getting Started

## Prerequisites
- Node.js (v14+ recommended)
- npm

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/mpbarbosa/mpbarbosa_site.git
   cd mpbarbosa_site
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm start
   ```

## Building for Production
Run:
```sh
npm run build
```

## Testing
Run:
```sh
npm test
```
