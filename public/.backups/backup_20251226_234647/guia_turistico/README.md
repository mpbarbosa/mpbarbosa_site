# Guia Turístico - Public Content

This directory contains public content for the Guia Turístico (Travel Guide) application.

## Contents

- Travel guide web interface
- Tourism data and visualizations
- Interactive maps and location information
- Public API endpoints for tourism data
- IBGE (Brazilian Institute of Geography and Statistics) data integration

## Access

Files in this directory will be accessible via:
- `https://yourdomain.com/submodules/guia_turistico/`
- Tourism data API endpoints
- Interactive travel planning tools

## Features Available

- Brazilian tourism destination guides
- IBGE demographic and geographic data
- Interactive visualizations
- Location-based services
- Travel planning tools
- Cultural and historical information
