# Public Documentation

This directory contains documentation that is intended for public access.

## Contents

- User guides and tutorials
- API documentation
- Project showcases
- Technical specifications
- Public reports and summaries

## Format Guidelines

- Use web-friendly formats (HTML, PDF, Markdown)
- Ensure proper styling and formatting
- Include navigation and search functionality
- Keep content up-to-date and accurate

## Access Control

Unlike the internal `/docs` directory, files here are:
- Publicly accessible via web URLs
- Indexed by search engines
- Available without authentication
- Suitable for sharing and linking
