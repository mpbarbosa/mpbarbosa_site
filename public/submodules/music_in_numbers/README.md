# Music in Numbers - Public Content

This directory contains public content for the Music in Numbers Spotify analytics application.

## Contents

- Production builds of the web application
- Static HTML, CSS, and JavaScript files
- Demo versions with sample data
- User documentation and guides

## Access

Files in this directory will be accessible via:
- `https://yourdomain.com/submodules/music_in_numbers/`
- Direct linking to specific application pages
- CDN distribution for better performance

## Deployment

Content should be synchronized from `/src/submodules/music_in_numbers/src/` using:
1. Production build processes
2. Asset optimization and minification
3. Static file generation
4. Automated deployment scripts

## Features Available

- Spotify OAuth 2.0 authentication
- Music analytics and insights
- Data visualization and charts
- Export functionality (PDF, CSV, JSON)
- Theme management (light/dark/high-contrast)
- Real-time monitoring features
