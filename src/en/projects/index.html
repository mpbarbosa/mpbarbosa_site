Projects

Software built by directing AI coding agents

Claude Code, GitHub Copilot and Cursor do the typing. The architecture, the acceptance criteria and the verification before production are mine — and that is what separates a prototype from something that stays up.

In production

  • Portal Brasileirão — Companion app for the Brazilian Série A championship

    Standings, fixtures and statistics for the Série A. OAuth login, Material Design 3 tokens and a live /api/health endpoint. Seven GitHub Actions workflows including rollback, with a documented flip-back drill, and keyless deploys over OIDC. When no API token is available the app falls back to a frozen snapshot instead of failing. React 19 · TypeScript · Express 5 · Tailwind 4 · AWS · 1,523 unit tests and 46 end-to-end Playwright specs · 906 commits in five weeks (23 August–29 September 2026)

  • Agora na Copa 2026 — Companion app for the FIFA World Cup 2026

    Monte Carlo simulator for qualification odds, using a Dixon-Coles model and the Article 13 FIFA tie-breaking criteria applied in the correct order. External integrations (FIFA API, Open-Meteo, Google Trends) each have their own fallback. Served by nginx and systemd. React 19 · TypeScript · Express · AWS · 267 unit tests and 37 end-to-end Playwright specs · 1,203 commits
