Projetos

Software construído dirigindo agentes de código

Claude Code, GitHub Copilot e Cursor fazem a digitação. A arquitetura, os critérios de aceite e a verificação antes da produção são meus — e é isso que separa um protótipo de algo que fica no ar.

Em produção

  • Portal Brasileirão — Companion do Campeonato Brasileiro Série A

    Acompanhamento de tabela, jogos e estatísticas da Série A. Login OAuth, tokens Material Design 3 e endpoint /api/health no ar. Sete workflows de GitHub Actions, incluindo rollback, com um drill de flip-back documentado, e deploy keyless via OIDC. Quando não há token da API disponível, o app cai para um snapshot congelado em vez de quebrar. React 19 · TypeScript · Express 5 · Tailwind 4 · AWS · 84 testes unitários e 46 specs Playwright ponta a ponta · 1.597 commits em cinco semanas (23 de agosto a 29 de setembro de 2026)

  • Agora na Copa 2026 — Companion da Copa do Mundo FIFA 2026

    Simulador de Monte Carlo das chances de classificação, com modelo Dixon-Coles e os critérios de desempate do Art. 13 do regulamento da FIFA implementados na ordem correta. Integrações externas (FIFA API, Open-Meteo, Google Trends) têm fallback próprio. Servido por nginx e systemd. React 19 · TypeScript · Express · AWS · 34 testes unitários e 37 specs Playwright ponta a ponta · 1.279 commits

Experimentos e ferramentas

  • ai_workflow — Pipeline de verificação para desenvolvimento assistido por IA

    Automatiza a etapa que costuma ficar de fora: tornar verificável o que um agente de código gerou, antes de ir para produção — revisão, documentação e testes.

  • gitx — TUI de Git integrada via MCP

    Interface de terminal para comandos Git, integrada a assistentes por Model Context Protocol (MCP).

  • olinda_copilot_sdk.ts — Wrapper TypeScript do GitHub Copilot SDK

    Camada em TypeScript sobre o SDK do GitHub Copilot para uso programático em ferramentas próprias.

  • Onde Estou? — Geolocalização em tempo real

    Mostra sua posição atual no mapa usando a API de Geolocalização do navegador, sem instalação.

  • MapaSP — Mapa interativo de São Paulo

    Mapa interativo da cidade de São Paulo com pontos de interesse e navegação por bairros.

  • Music in Numbers — Análise de dados Spotify

    Visualiza e analisa seu histórico de streaming do Spotify com gráficos e estatísticas.

  • Monitora Vagas — Monitoramento de vagas hoteleiras

    Monitora a disponibilidade de vagas hoteleiras e notifica quando surgem aberturas.

  • Bibliotecas publicadas no npm — bessa_patterns.ts, ibira.js e paraty_geocore.js

    Três pacotes publicados no registro do npm, ainda em versões iniciais.

  • Scripts de automação — Scripts utilitários no GitHub

    Coleção de scripts utilitários para tarefas do dia a dia de desenvolvimento, disponíveis no GitHub.
